## 🚀 Latest Project: News Website with Authentication

### 📌 Project Overview
This is a simple News Website with an authentication system.  
It ensures that only logged-in users can access full news details.

---

## ✨ Features
- 🔹 Users are redirected to the **Home Page** when they enter the website  
- 🔹 Clean and responsive **Navbar** with Login & Register options  
- 🔹 Users can easily **Register** and **Login**  
- 🔹 Protected routes:  
  - If a user tries to access news details without logging in → redirected to Login Page  
- 🔹 After login, users can view full news content  

---

## 🛠️ Tech Stack
- ⚡ Next.js  
- 🔐 Authentication System  
- 🍃 MongoDB (Database)
